# Support

## Questions and usage

Use GitHub Issues for reproducible product defects and bounded feature requests.

Before opening an issue:

1. check the current release notes;
2. search existing issues;
3. reproduce the problem against the latest stable release or current `main`;
4. include the smallest example that demonstrates the behavior.

## Security

Do not use public issues for vulnerabilities or sensitive financial data. Follow [SECURITY.md](SECURITY.md).

## Scope

CoFi is an infrastructure library/workspace. Support requests should focus on repository behavior, documented APIs, financial invariants, and reproducible integration problems.
