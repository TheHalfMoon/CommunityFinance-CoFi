## Method and reproducibility

The live CoFi tree, release, CI/workflow definitions and domain sources were read first. Public donor repositories were cloned without importing source into CoFi. Git revision/file trees and root license/notice files were inventoried; targeted implementation files were read for ownership, numerical/transaction semantics, API dependencies and failure behavior. Local file SHA-256 receipts are reproducible by reading the same pinned raw paths; Git checkout line-ending conversion can affect a local-byte SHA-256, so the full commit/path remains the source identity. No donor tests/builds, provider credentials or performance experiments were used.

Founder search included the full accessible inventory and code searches for idempotency, capability, connector, transaction and exact-head, then selected public repositories for deeper pinned reads. Private repositories are excluded from public evidence. Additional code-search hits were screening only and do not imply reusable production units. Gomrey indexing lag was resolved using its live clone pin. Graft returned 404; no Graft interface or qualification is asserted.

Current CoFi workflow runs/releases/open work and limitations are in [LIVE_STATE.md](LIVE_STATE.md). An empty ruleset collection does not prove absence of branch protection: the branch-protection endpoint returned 403. The integration cannot certify protected-branch configuration. Preserve documented governance regardless.
